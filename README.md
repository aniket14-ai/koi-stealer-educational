# 🐟 Koi Stealer - macOS Stealer Simulation (Educational)

This project demonstrates a **safe, educational simulation** of a macOS stealer called *Koi*, inspired by real-world malware used by North Korea-linked threat actors targeting cryptocurrency users.

---

## 🧬 What’s Included

- 🐍 **Python Stealer Simulation** (`koi_stealer_mock/`) that mimics browser and wallet data exfiltration.
- 🌐 **Phishing-Themed Demo Website** (`website/`) to simulate a fake MetaMask wallet update prompt.
- 📚 MITRE ATT&CK references for awareness and training.

---

## 🚨 Ethical Use Notice

> This repository is for **educational and awareness purposes only**. It contains **no real malware**, and does **not steal or transmit any real data**.
